# Quantitative Finance Case Studies

Applied quantitative finance in Python: each case study starts from real market data, builds the statistical tools the problem needs, and ends with a recommendation a decision-maker could act on.

| Case study | Question | Headline finding |
|---|---|---|
| [Estimation Risk in Portfolio Optimization](portfolio-estimation-risk/) | Can a portfolio manager trust a mean-variance optimizer built on historical data? | Noisy return estimates make the unconstrained optimizer take extreme positions. Its walk-forward Sharpe of 0.19 trails equal-weight (0.76) and SPY (0.85). |

More case studies (FX carry trade, market making, options pricing) coming soon.
